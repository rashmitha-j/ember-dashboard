# Ember Dashboard

A sales and revenue operations dashboard built with Next.js, React, Tailwind CSS and Recharts.
Created by Rashmitha J.

## Sections
Overview · Pipeline · Deals · Customers · Team · Forecasting · Reports · Settings

## Getting started
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Notes
- All data is sample data defined inside the components (no backend yet).
- Theme colors live in `app/globals.css` (`--accent` is the orange brand color).
- The product name is set in `app/layout.tsx` and `components/dashboard/sidebar.tsx`.
